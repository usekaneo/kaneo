Connecting a different repository while one is already linked returns **409**. Disconnect the current integration first so its old issue and pull-request numbers cannot be reused against the new repository. Local tasks remain; old external links and saved import progress are removed by disconnecting. Reverification of the same numeric repository preserves existing links and preferences, including when its name or installation changes. Concurrent configuration changes also return409; refresh before retrying.
