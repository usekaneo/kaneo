---
title: "Start and check Kaneo"
description: "Start the containers and confirm the instance is ready."
---

If you are installing for the first time, use the complete [Docker Compose guide](/core/installation/docker-compose). It includes the configuration, secrets, startup, and first sign-in.

From the directory containing your Compose file:

```bash
docker compose up -d
docker compose ps
curl --fail http://localhost:5173/api/health
```

If a service is unhealthy, run `docker compose logs --tail=100 kaneo postgres` and follow [Troubleshooting](/core/operations/troubleshooting).

After changing `.env`, run `docker compose up -d --force-recreate kaneo` so the container receives the new values.

For a public instance, continue with [Nginx and HTTPS](/core/reverse-proxy/nginx).
