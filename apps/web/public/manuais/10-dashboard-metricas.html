10 — Dashboard de métricas

Visão resumida de tarefas, prazos, responsáveis e contratos por projeto.

Onde fica na UI

  1. Menu lateral → Dashboard (métricas). URL: /dashboard/workspace/{workspaceId}/metrics
  2. Ou use Ajuda → tour Dashboard de métricas.

Como usar

  1. Selecione o projeto no seletor do topo.
  2. Veja cards de total, concluídas, em andamento e atrasadas.
  3. Role para gráficos de colunas, prioridades, responsáveis e contratos.

Sem projeto selecionado, a página fica vazia — escolha um projeto para carregar os dados.
