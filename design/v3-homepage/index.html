Before you get started

Is Kaneo free to self-host?

Yes. Kaneo is MIT licensed and free to self-host, with single sign-on included. Run it alongside PostgreSQL with Docker Compose, or deploy with the official Helm chart. You manage infrastructure, updates, and backups.

Does Kaneo have Gantt charts?

Yes. Gantt and calendar views sit alongside boards, lists, and backlog planning. Use start and due dates to plan work on a timeline.

Is single sign-on included?

Yes. The free self-hosted build supports Google, GitHub, Discord, and custom OAuth/OIDC providers, without a separate paid edition.

Can AI clients work with Kaneo?

Yes. Kaneo provides an MCP server through the @kaneo/mcp package and an HTTP endpoint. Compatible clients can read and update tasks with an API key, subject to workspace permissions.
